# Authority and reading order

## Authority order

1. `AGENTS.md`
2. Current `IMPLEMENT.md`
3. Current explicit contracts and acceptance criteria
4. Current architecture decisions
5. Current schemas and implementation behavior
6. Current tests
7. Historical references under `reference/`

Historical references describe the lost implementation and intended target. They cannot override the factual state of the rebuilt repository.
